# Admin Panel — идеи и план

Документ с идеями для админ-панели Qulpynai: функции, экраны, API и UX.

---

## 1. Назначение

Админ-панель для владельца/менеджера сети пекарен:
- управление заказами,
- меню и товары,
- локации,
- промоакции,
- пользователи и loyalty,
- отчёты и аналитика.

---

## 2. Варианты реализации

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **Отдельное веб-приложение** | Удобно с десктопа, не нужна модерация в App Store | Нужен отдельный стек (React/Vue/Next) |
| **Секция в iOS-приложении** | Один кодбаз, доступ с телефона | Долго, много экранов, сложно для планшета |
| **Упрощённый iPad-режим** | iPad для кухни/кассы | Только iPad |
| **PWA** | Один backend, быстрый старт | Меньше возможностей, чем нативное |

**Рекомендация:** начать с PWA или простого веб-SPA для быстрого MVP, позже — нативное решение при необходимости.

---

## 3. Роли и доступ

| Роль | Права |
|------|-------|
| **Super Admin** | Всё: юзеры, локации, меню, промо, отчёты |
| **Location Manager** | Своя локация: заказы, меню, склад |
| **Kitchen / Barista** | Просмотр и статусы заказов |
| **Support** | Просмотр заказов, юзеры (read-only) |

## 4. Экраны и функции

### 4.1 Dashboard (главная)

- Сводка за сегодня: кол-во заказов, выручка.
- Графики: выручка по дням/неделям.
- Топ товаров.
- Список активных заказов в реальном времени.
- Уведомления: новые заказы, низкий запас.

### 4.2 Заказы

- Список: фильтр по дате, статусу, локации, способу получения.
- Карточка заказа: позиции, адрес, оплата, история статусов.
- Действия: принять, в работе, готов, выдан/доставлен, отменить.
- Печать чеков/этикеток (при наличии принтера).

### 4.3 Меню и товары

- **Категории:** CRUD, сортировка.
- **Товары:** CRUD, фото, цена, описание, availability.
- **Опции:** размеры, молоко, допы (add-ons) и их цены.
- **Наличие по локациям:** какой товар есть в каких точках.
- Массовые операции: изменение цен, скрытие/показ.

### 4.4 Локации

- CRUD локаций.
- Адрес, часы работы, контакты.
- Привязка меню к локации.
- Онлайн/офлайн-режим точки.

### 4.5 Промоакции

- Создание промокодов (WELCOME20, SUMMER10 и т.д.).
- Тип: процент или фикс. сумма.
- Условия: мин. сумма, категории, первый заказ.
- Даты действия, лимит использований.

### 4.6 Loyalty

- Настройка очков за заказ (например, 1₽ = 1 point).
- Уровни и бонусы.
- Просмотр балансов пользователей.
- Ручное начисление/списание (при необходимости).

### 4.7 Пользователи

- Поиск по email/телефону.
- Просмотр заказов, loyalty, адресов.
- Блокировка/разблокировка.
- Экспорт (CSV) для рассылок.

### 4.8 Настройки

- Брендинг: логотип, цвета.
- Платёжная система: Apple Pay merchant ID, подключение эквайринга.
- Уведомления: email/SMS для новых заказов.
- Часы работы по умолчанию.

### 4.9 Отчёты и аналитика

- Выручка: по дням, неделям, локациям, категориям.
- Популярные товары.
- Средний чек.
- Конверсия (заказы / пользователи).
- Экспорт в CSV/Excel.

## 5. API для админки

Все эндпоинты требуют авторизацию (Bearer token) и проверку роли.

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/admin/dashboard` | Сводка за день/период |
| GET/POST | `/admin/orders` | Список, фильтры |
| PATCH | `/admin/orders/:id` | Изменить статус |
| CRUD | `/admin/categories` | Категории |
| CRUD | `/admin/products` | Товары |
| CRUD | `/admin/locations` | Локации |
| CRUD | `/admin/promotions` | Промокоды |
| GET | `/admin/users` | Поиск пользователей |
| GET | `/admin/reports/revenue` | Отчёт по выручке |

---

## 6. UX-рекомендации

- **Быстрый доступ:** горячие клавиши для частых действий.
- **Офлайн:** базовый режим при потере сети (просмотр, кэш).
- **Мобильная версия:** приоритет — просмотр заказов и смена статусов.
- **Real-time:** WebSocket или polling для новых заказов.
- **Печать:** поддержка термопринтеров для чеков/наклеек.

---

## 7. Технический стек (пример)

- **Frontend:** Next.js / React + Tailwind / shadcn/ui
- **Auth:** JWT + refresh tokens, роль в payload
- **Real-time:** Supabase Realtime / Pusher / Socket.io
- **Backend:** тот же API, что и для мобильного приложения, плюс `/admin/*`
